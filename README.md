# Applied Research Tools

A customer-facing showcase for three focused research products developed by Andrew Esparon:

- **QuantFit** — applied econometrics on iPhone and iPad, including panel data, ARDL-family, VAR/VECM, dynamic GMM, diagnostics, scenario shocks and research exports.
- **Tabula Stats** — turn regression output from Stata, R, SPSS, QuantFit, screenshots, photos or PDFs into publication-ready tables; also build charts, equations and matrices.
- **BellmanDSGE** — a native macOS workbench for specifying, solving, simulating, validating and exporting auditable DSGE models.
